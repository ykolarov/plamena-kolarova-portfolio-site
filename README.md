# Portfolio site notes

This is a single-page static portfolio starter built from the structure of the PSD:

- Hero
- About
- Services
- Field-based portfolio sections
- Contact

## What to replace first

1. Update contact links in `index.html`.
2. Replace the placeholder project visuals inside each `.field-media` item with your own `<img>` elements.
3. Edit the copy in the hero and about sections once your final positioning is decided.

## Adding more fields

Duplicate one `.field-section` block in `index.html`, then edit:

- the field title
- the short description
- the tools list
- the four image slots

## Files

- `index.html` — page structure and content
- `styles.css` — visual design and responsive layout
- `script.js` — reveal animations
